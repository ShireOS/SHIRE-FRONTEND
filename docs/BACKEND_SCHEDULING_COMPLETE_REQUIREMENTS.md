### DELETE /schedules/{schedule_id}
```python
@router.delete("/schedules/{schedule_id}", status_code=204)
async def delete_schedule(schedule_id: UUID, session: AsyncSession):
    schedule = await session.get(Schedule, schedule_id)
    if not schedule:
        raise HTTPException(404, "Schedule not found")
    if schedule.status == 'published':
        raise HTTPException(409, "Cannot delete published schedule")

    await session.delete(schedule)
    await session.commit()
    return Response(status_code=204)
```

### PATCH /schedule-items/{item_id}
```python
@router.patch("/schedule-items/{item_id}")
async def update_schedule_item(
    item_id: UUID,
    data: UpdateScheduleItemRequest,
    session: AsyncSession
):
    item = await session.get(ScheduleItem, item_id)
    if not item:
        raise HTTPException(404, "Schedule item not found")

    # Check schedule is editable
    schedule = await session.get(Schedule, item.schedule_id)
    if schedule.status == 'published':
        raise HTTPException(409, "Cannot edit published schedule")

    # Update fields
    if data.waiter_id:
        item.waiter_id = data.waiter_id
    if data.shift_start:
        item.shift_start = data.shift_start
    if data.shift_end:
        item.shift_end = data.shift_end
    if data.role:
        item.role = data.role

    item.source = 'manual'  # Mark as manually edited
    await session.commit()
    return item
```

### POST /schedules/{schedule_id}/items
```python
@router.post("/schedules/{schedule_id}/items")
async def create_schedule_item(
    schedule_id: UUID,
    data: CreateScheduleItemRequest,
    session: AsyncSession
):
    schedule = await session.get(Schedule, schedule_id)
    if not schedule:
        raise HTTPException(404, "Schedule not found")
    if schedule.status == 'published':
        raise HTTPException(409, "Cannot modify published schedule")

    item = ScheduleItem(
        id=uuid4(),
        schedule_id=schedule_id,
        waiter_id=data.waiter_id,
        role=data.role,
        shift_date=data.shift_date,
        shift_start=data.shift_start,
        shift_end=data.shift_end,
        source='manual'
    )

    session.add(item)
    await session.commit()
    return item
```

## 🤖 CRITICAL: LLM Integration - NO DEFAULTS, ALWAYS CALL LLM

**The AI summary MUST be generated by calling an LLM EVERY SINGLE TIME.**

### Requirements:
- ✅ **Call LLM** after every schedule generation (Claude API, OpenAI API, etc.)
- ✅ **Generate fresh** reasoning each time (no caching, no reuse)
- ✅ **Store in database** as `schedule.schedule_summary`
- ❌ **NO default text** - if LLM fails, store null (frontend has fallback)
- ❌ **NO templates** - LLM generates unique explanation each time
- ❌ **NO caching** - even for same inputs, call LLM fresh

### Why This Matters:
Just like waiter insights call LLM to generate `llm_summary`, scheduling needs the SAME approach:
- Each schedule is unique (different staff, availability, constraints)
- LLM sees the actual data and explains real decisions
- Summary changes based on what AI actually did

### Backend Flow:
```python
# After scheduling engine completes
schedule = await create_schedule(...)  # Creates shifts

# ALWAYS call LLM (no shortcuts!)
summary = await call_llm_for_schedule_summary(
    schedule_data=schedule,
    metrics=summary_metrics,
    gaps=coverage_gaps
)

schedule.schedule_summary = summary  # Could be null if LLM fails
await session.commit()
```

### What Frontend Shows:
- **If summary exists:** Displays LLM-generated paragraph
- **If summary is null:** Shows calculated stats as fallback (frontend handles this)
